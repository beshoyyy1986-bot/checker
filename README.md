# JAMAIKA CHECKER BOT

البوت يوفر خدمات فحص البطاقات الائتمانية عبر بوابات مختلفة مع دعم للبروكسيات والمستخدمين المؤهلين.

## الميزات الأساسية

- فحص البلاط الائتماني (CVV/Exp)
- دعم البروكسيات المتعددة
- نظام اشتراكات ورموز تفعيل
- فحص المواقع والبحث عن بوابات الدفع
- خاصية إرسال الجماعات بسرعة مع شريط تقدم

## التثبيت والإعداد

### متطلبات النظام
- Python 3.7+
- مكتبات من `requirements.txt`

### الخطوة الأولى: إنشاء بوت جديد من @BotFather
- قم بإرسال `@BotFather` الأمر `/newbot`
- أعد تسمية البوت والرمز المخصص
- انسخ التوكن

### الخطوة الثانية: قم بإنشاء ملف `.env`
```env
BOT_TOKEN=YOUR_BOT_TOKEN_HERE
ADMIN_ID=YOUR_ADMIN_USER_ID  # معرف المستخدم الخاص بالمسؤول
```

### الخطوة الثالثة: تنزيل المكتبات
```bash
pip install -r requirements.txt
```

### الخطوة الرابعة: تشغيل البوت
```bash
python bot.py
```

## تعليمات النشر

### على Render أو Railway
1. ضع ملف الـ repo على Git
2. اربط الـ repo باستخدام منصة Render/Railway
3. قم بتحديد `Procfile` كـ Entry Point
4. قم بوضع متغيرات البيئة في `Environment Variables` (`BOT_TOKEN`, `ADMIN_ID`)
5. قم بربط Volume لتخزين البيانات عند الحاجة

> ملاحظة: يجب أن يحتوي مجلد `/data` على ملفات التخزين عند النشر في.Render أو Railway

## استخدام البوت
للسماح للمستخدمين بالتفاعل مع البوت، يرجى الانتقال إلى رابط البوت الموجود في التلغرام.
