# 🚪 Gate Hunter - صائد البوابات

نظام متقدم للبحث عن بوابات الدفع في المواقع الأجنبية باستخدام Bright Data SERP API.

## ✨ المميزات

- 🔍 **بحث متقدم** عبر Bright Data SERP API
- 🌍 **بحث من دول مختلفة** باستخدام دوركات Google مخصصة
- 💳 **كشف 30+ بوابة دفع** (Stripe, PayPal, Braintree, ...)
- 🛡️ **تحليل 10 أنظمة حماية** (Cloudflare, Akamai, Imperva, ...)
- 🔬 **فحص عميق** للصفحات بحثاً عن نماذج الدفع
- 📊 **إحصائيات مفصلة** عن عمليات البحث والفحص

## 📁 الملفات

```
modules/gate_hunter/
├── __init__.py          # تهيئة الوحدة
├── config.py            # إدارة الإعدادات
├── database.py          # عمليات قاعدة البيانات
├── handlers.py          # معالجات Telegram
├── scanner.py           # محرك الفحص
├── bright_data.py       # Bright Data SERP API
└── signatures.py        # بصمات البوابات والحماية
```

## ⚙️ الإعدادات

### 1. Bright Data Credentials

افتح قائمة **⚙️ الإعدادات** → **🔑 Bright Data Credentials**:

- **Customer ID**: معرف العميل من Bright Data
- **Zone**: اسم الـ Zone (الافتراضي: `serp_api`)
- **Password**: كلمة مرور الـ API

### 2. إعدادات البحث

- **عدد النتائج الافتراضي**: عدد المواقع المراد فحصها (10-1000)
- **سقف محاولات البحث**: مضاعف المحاولات عند عدم العثور على نتائج كافية

### 3. إعدادات الفحص

- **الفحص العميق**: فحص الصفحات بحثاً عن نماذج دفع
- **إظهار المحميات**: إرسال المواقع المحمية أيضاً للنتائج

## 🚀 الاستخدام

### البحث بدورك مخصص

1. اضغط **🔍 بحث جديد**
2. أدخل الدورك (مثل: `site:.de checkout "credit card"`)
3. اختر الدولة
4. اختر عدد النتائج
5. انتظر النتائج

### استخدام دوركات جاهزة

1. اضغط **📋 دوركات جاهزة**
2. اختر نوع الدورك
3. اختر الدولة والعدد
4. ابدأ الفحص

### فحص URL واحد

أرسل رابط مباشر للبوت وسيقوم بفحصه تلقائياً.

## 🔐 الأمان

- **للأدمن فقط**: Gate Hunter متاح فقط في لوحة الأدمن
- **حماية الصلاحيات**: جميع الـ callbacks تتحقق من المستخدم
- **إخفاء كلمات المرور**: لا تظهر كلمات المرور في الإعدادات

## 💾 البيانات

- **الإعدادات**: `gate_hunter_config.json` في DATA_DIR
- **قاعدة البيانات**: `gate_hunter.db` في DATA_DIR
- **تلقائي**: إنشاء المجلدات والملفات عند الحاجة

## 🛠️ التطوير

### إضافة بوابة جديدة

عدل `signatures.py` وأضف البوابة إلى `PAYMENT_GATEWAYS`:

```python
'gateway_name': {
    'name': 'Gateway Name',
    'patterns': [r'pattern1', r'pattern2'],
    'domains': ['gateway.com']
}
```

### إضافة نظام حماية

عدل `signatures.py` وأضف النظام إلى `SECURITY_SIGNATURES`:

```python
'security_name': {
    'name': 'Security Name',
    'headers': ['x-security-header'],
    'patterns': [r'security.*pattern']
}
```
